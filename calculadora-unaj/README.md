# Calculadora de Calificación de Hoja de Vida - UNAJ

Primera versión de una calculadora web referencial basada exclusivamente en el **Anexo 3 - Tabla de Calificación de Hoja de Vida** proporcionado para el desarrollo.

## Acceso

La aplicación se publica como una página independiente dentro del GitHub Pages personal:

https://yasmanivargas.github.io/calculadora-unaj/

## Alcance

- Calcula 10 criterios de la hoja de vida.
- Respeta los puntajes máximos por criterio.
- Puntaje total máximo: 70 puntos.
- Incluye impresión de resumen.
- No utiliza servidor ni almacena los datos ingresados.
- Conserva visibles las inconsistencias de redacción/numeración presentes en el documento fuente, sin sustituirlas por criterios externos.

## Nota

Herramienta referencial. No sustituye la evaluación del jurado calificador.
